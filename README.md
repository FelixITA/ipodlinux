# my Contribution to iPodLinux Project

A small collection of games I wrote for **iPodLinux**, mostly during two- or three-night coding sessions.

This repository is preserved as a piece of early iPod hacking and open-source history.

## About iPodLinux

[iPodLinux](http://www.ipodlinux.org/) was an open-source project that ported **µClinux to Apple's iPod**, turning what was designed as a music player into a small, hackable Linux computer.

The project included **Podzilla**, an alternative user interface and application launcher, together with a growing collection of utilities, games, demos, emulators and other experiments.

At the time, being able to boot Linux on an iPod — and then write software that interacted directly with its display, controls and hardware — was quite remarkable.

## This repository

These are games I wrote while contributing to and experimenting with iPodLinux.

They were small projects, typically conceived and implemented in **two or three nights**.

The objective wasn't sophisticated software architecture. It was much simpler:

**Have an idea, write it, compile it, put it on the iPod, and see it running on (mine) real hardware.**

That was a large part of what made iPodLinux so much fun.

The limited hardware, unusual controls and small display also made even simple games an interesting programming exercise.

## Historical context

This code comes from a very different era of portable computing.

The original iPods had extremely constrained hardware compared with modern devices, and Apple never intended them to be general-purpose computers.

iPodLinux changed that.

The community reverse-engineered the hardware, ported Linux, developed drivers and bootloaders, built Podzilla, and created applications ranging from simple utilities and games to emulators and ports of much larger software.

This repository contains my small contribution to that ecosystem.
